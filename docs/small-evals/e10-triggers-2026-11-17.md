## Method and reproduction boundary

`portfolio/small-evals/e10_audit/validate_triggers.py` reads the six unchanged patch
definitions from `sabotage.py`, requires exactly one match per patch, and compiles
selected function ASTs in memory. It never writes mutated production code. E01
executes its reporting main function against three two-row synthetic runs in a
temporary directory, using the real bootstrap helpers. E05 executes `stream_one`
with the real incremental JSON parser, a fake HTTP response and a deterministic
clock. Other checks exercise the option parser and numeric/tool graders. Explicit
dependency injection avoids importing service-starting runner modules.

Run from the private workspace:

```sh
python portfolio/small-evals/e10_audit/validate_triggers.py
```

Python 3.12.7 / NumPy 1.26.4. The saved JSON records expected, original and injected
observations plus SHA-256 hashes of each source file. A regular pytest regression
in `tests/test_e10_triggers.py` exercises the same six checks. The existing E08
test file was already modified before this work and was not edited.

The public draft includes this report, the observation JSON and the validator as
a method reference. It does not include all dependent private source modules or
the Tally parser, so the validator is not independently runnable from the public
checkout. No private datasets, model responses or task transcripts are included.
